# v1.3.4 — 群聊断点采集、转录检查与原文审阅修复

相对 **v1.3.3** 的代码更新（2026-09-15）。

## 自动化与群聊

- 群聊改为同轮逐窗口断点保存，原生转文字后立即落断点；新增浏览器工作流和本地 checkpoint 表单，减少中断后重复操作。
- 最新端、连续窗口、重叠覆盖和内容哈希由断点计算验证，不接受手填成功标志；诊断 begin/end 保存真实阶段耗时，未结束或最终失败不能生成成功凭证。
- 群聊 adapter 只读本轮产物；最终库支持账本复用。连续语音扩展通过真实文字前缀和唯一匹配确认身份，事务更新原记录并保存审计，不重复插入；调度器允许已入库语音组的有效扩展输出。
- 现有 Codex 自动化已同步最新规则，移除旧手写凭证指令。保持北京时间 **00:00、08:00、12:30、16:00、20:00**，不新增任务、不调整模型。
- 保留 X helper、Discord/exporter、Substack/helper 入口及既有作者、上下文、翻译、去重规则。明确 X/抖音订阅预览隔离，Substack 已授权会员文章正常处理。
- 每轮报告实际新增/更新标题、时间与 ID，区分恢复、更新、重复和失败；图片检查要求实际响应体，不能仅凭 HTTP 200 判定成功。

## 抖音转录与微信公众号

- 公开主页转录构建增加高置信度证券名称/财经术语检查、标准术语命中及纠错数量审计，已知错误残留时拒绝构建。
- 增加“美联储利率决议”等纠错；此为有限词表检查，**不是全市场证券名称核验，也不替代上下文人工/模型复核**。
- 补充用户已提供财躺平文章的财经段落配置，保留发布时间和原文，排除动物救助及无关随笔；不主动抓取未提供文章。

## 网页

- A 股板块改为更细的主分类，拆分存储、处理器、制造设备、光通信与计算基础设施；单条原文选一个主板块，降低重复归类。
- 原文展开按钮依据实际显示溢出决定是否出现，避免全文已显示仍提示展开。
- 历史观点正文允许选择和复制；空白区域仍可拖动。
- 返回每日原文时展开日期和作者分组、聚焦高亮目标，避免与回页首滚动冲突。
- 图片加载失败增加有限重试。本机图片曾因 API 进程读取权限错误而失败，重启后实际解码验证恢复；**本版本不宣称从代码层面永久解决操作系统权限问题**。

## 验证与范围

- 52 项脚本 unittest 通过（含群聊断点/复用/修订、前检、证券术语、Discord、X 长帖及订阅规则）。
- Python 编译、前端与群聊 JavaScript 语法、采集入口 Shell 语法、git diff 检查通过。
- 前序本机浏览器验证：截图中的三张图片正常解码，原文跳转展开所有上级分组并聚焦目标。
- 本次为发布检查，不额外触发整轮在线采集；在线登录、网站风控及系统权限仍可能影响运行。
- 只发布代码和文档。不包含数据库、采集原文、媒体、Cookie/Token、浏览器 profile、运行输出及一次性本地回补脚本。部署到另一台机器后仍需独立配置定时任务和登录态。
