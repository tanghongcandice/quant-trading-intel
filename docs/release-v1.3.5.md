# v1.3.5 — 增量采集补全闭环与全文审阅

相对 **v1.3.4** 的代码更新，发布检查日期：2026-09-18。

## 1. 群聊采集与缺口恢复

- 已验证窗口中完整的语音组可以先入库，不再被一张异常分享卡片阻塞；缺少片段的语音组整体留置，不拆成不完整正文。
- 强化虚拟列表移位、相邻消息与作者/时间边界检查；保留窗口哈希和转写来源验证，部分结果仍冻结群聊完整游标。
- 新增最终数据库中的 `group_retry_queue` 和尝试审计。缺失语音、异常卡片跨轮保留，抓到内容先进入 `awaiting_import`，只有对应正文证据通过最终入库事务核验才销账；条目暂时不在页面上不代表完成。
- 群聊脚本增加原生转文字有界重试、点击分享卡片读取实际播放 URL、单条失败继续其他消息；入口生成 `group_retry_report.json`，保留未解决原因。
- 新增独立持久化 Playwright profile 的群聊采集器、并发锁与启用门禁。**尚未完成真实登录和完整覆盖验收，不默认启用，不将离线测试等同在线补采成功**；原 CUA 通道仍按最新规则执行。

## 2. X、Discord 与翻译

- X helper 改进公开长帖详情稳定性判定，引用卡片的展开控件不再影响主帖完整性；失败保留 `pending_retry` 和错误。
- 每来源有界轮转重试公开截断记录，允许旧发布时间的补全候选通过增量过滤；更长且完整的原文事务原位更新，保留原 ID 和修订审计。
- X、Discord、Substack 英文缺少或空白中文翻译时进入本轮 `pending_codex_review.jsonl`；补全 X 原文需重新翻译，不复用截断译文。原文不改动，纯网址保持免翻译。
- Discord 搜索结果回复上下文提取增加可见属性回退；部分覆盖保留已抓内容，同时报告覆盖不足，避免无声漏项或冒报全量成功。
- 静态图片恢复支持核对原附件 URL、文件路径、大小与 SHA-256，保留修订审计且不改消息正文。此能力不意味着自动修复所有历史失效图片或系统权限问题。

## 3. 抖音公开转录与财躺平

- 公开占位转录按最终库状态进入有限重试：每来源每轮最多 3 条、间隔 6 小时、自动最多 5 次；完整内容不重做，明确会员作品不进入公开补全队列。
- 下载失败或元数据缺失报告为转录待补全，保留真实错误，不再直接宣称“视频无可转录音轨”；单作品失败不阻塞其余作品构建。
- 增加授权播放页证据桥接、实际播放音轨恢复候选构建及显式逐条复核工具；证券/财经术语自动检查不再冒称 Codex 已阅读全文复核。
- 经复核的完整转录事务原位替换公开占位记录，验证作者归属、保留 ID/发布时间、刷新全文索引并记录审计。
- 新增 `douyin_completion.json` 最终库检查，区分来源失败、待审、留置与真实完成；退出 0 不等于所有正文已补齐。
- 补充用户指定的财躺平文章财经段落配置；不主动扩大公众号采集范围。

## 4. 网页审阅

- 美股和 A 股筛选增加标题、原文、中文译文全文检索；命中高亮、自动展开折叠正文、显示匹配数，Enter/Shift+Enter 和按钮切换命中位置。
- 搜索框放在现有筛选项之后，调整布局而非独占整行。
- 历史观点目录改为一级行业归组、二级链接跳转；市场与宏观靠前，目录可换行。
- 抖音历史观点显示视频标题；查看原文使用新标签页链接，通过原文 ID 定位并展开每日审阅，保留当前浏览页。
