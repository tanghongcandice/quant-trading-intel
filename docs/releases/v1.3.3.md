# v1.3.3 — Reliable group preflight and aligned Douyin profile ingestion

Compared with `v1.3.2`, this release hardens every scheduled Douyin group read and removes a Panyi-only legacy gate that could silently suppress current profile updates.

## Douyin group reliability

- Separates Chrome tab discovery from an actual group DOM read; a visible tab alone no longer counts as collection success.
- Requires same-run evidence for the exact group, latest visible anchor, and the final-database cursor's two-hour overlap window.
- Records timestamped connection, DOM-read, processing-ledger reuse, and receipt stages in a per-run diagnostics JSONL file.
- Retries a failed connection or DOM read after short bounded delays, without bypassing screen lock or authentication, and continues other sources if the group remains unavailable.
- Reuses completed voice batches only when their fingerprint still matches and their item exists in the final database, avoiding repeated native speech-to-text work.
- Treats display and service power events as diagnostic evidence only; they do not independently prove that a historical session was locked.

## Panyi and Jiujiujiucai alignment

- Uses the same final-database cursor and two-hour overlap candidate rules for both current profile feeds.
- Keeps Panyi's stricter rendered-profile ownership verification while removing its legacy backfill-state early return and current-feed batch limit.
- Prevents a historical 403, retry deadline, or incomplete backfill flag from reporting a false successful run with zero current candidates.
- Adds regression coverage showing that all current Panyi works after the final cursor remain eligible regardless of legacy backfill state.

## Recovery performed with this release

- Recovered four Panyi public works published on September 7–8, 2026 that the legacy gate had skipped.
- Downloaded their final media, extracted speech audio, generated Whisper transcripts, and imported all four through the transactional ingestion service.
- Advanced the Panyi final-store cursor only after successful import; the overlapping September 6 item was correctly skipped as an existing database record.

## Verification

- Chrome diagnostics, group run-gate, processing-ledger/final-store, and Panyi policy tests pass.
- Python compilation, `git diff --check`, SQLite integrity, source/external-ID uniqueness, and local API visibility checks pass.

Runtime databases, browser sessions, collected content, credentials, diagnostics output, and one-time local recovery scripts are not included in the release.
