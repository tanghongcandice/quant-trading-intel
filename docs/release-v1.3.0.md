# v1.3.0

对比上一发布版本 v1.2.2（52e50a9）。

## 本次迭代

- 每日五次采集时间调整为 Asia/Shanghai 00:00、08:00、12:30、16:00、20:00，仅将原 11:00 改为 12:30；潘姨独立补采任务不变。
- 新增抖音「宇菠萝的认知圈1群」接入：快照桥接、本地构建与入库校验。仅保留明确核实的群主/管理员消息，排除普通成员和系统通知；连续语音按发送者、时间、缺口和语义组织，保留分段。视频分享保存实际作品链接、标题与视频作者，区分群发送者。
- 群聊快照过期时报错；明确早期历史未完整、分享视频正文未转写，不能将已读取卡片等同于已完成全文采集。
- X/抖音明确的订阅截断预览统一为 review_only，保留原文审阅但排除分析。X helper 保存订阅提示证据；仅有省略号不判定付费。Substack 已有会员权限，继续按正常内容处理。
- X 入口默认使用仓库 vendor/x-crawler helper，避免发布代码与用户目录中的旧副本漂移；仍支持 X_CRAWLER_SKILL_SCRIPT 显式覆盖。
- 增加潘姨逐条补全、所有权核验、失败保留当前作品、重新下载资料及转录复核工具；HTTP 错误停止选项仅显式启用，不改变其他采集默认行为。
- 前端新增群聊信息源及对应标签；修正“查看全部日期”后重新加载恢复当天筛选的问题。

## 自动化与运行边界

- 每日任务仍调用 scripts/run_daily_collection.sh；群聊读取由任务通过已登录浏览器执行，再调用 scripts/build_douyin_group.py 和统一 ingestion_service 入库。单独运行 shell 不会自动操作群聊语音菜单，不可将旧快照改时间冒充刷新。
- 定时任务指令已同步上述范围、订阅例外和每轮新增清单。运行时需保留本机登录态，不发布 Cookie、Token、数据库、采集正文和运行日志。
- 图片故障本次确认是 API 进程读取文件出现 Operation not permitted；重启后浏览器实测恢复。这是本机运维修复，不宣称已经通过代码永久解决系统权限问题。后续校验应读取实际图片响应体，不只检查 HEAD/200。
- 历史清理和回填脚本是手动维护工具，不应在每日任务自动执行；执行前保留备份。

## 验证

群聊构建/角色/语音/视频分享、潘姨策略和订阅隔离回归测试；Python 编译与前端语法检查。未为发布触发一轮真实全来源采集，外部登录态与来源风控仍须在每轮运行报告中独立确认。
